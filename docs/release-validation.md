- B02/B03/B08/B09の順序、色名、70%、ファイル名、商品URLの対応を検査。
- ZIP内の各画像のバイト列がブラウザから保存した元画像と完全一致。SHA-256もmanifestと一致。
- confirmedByはhuman。未確認の他候補はcollection-reportにreviewとして残る。
- API認証値・applicationId・accessKeyを出力しないことを確認。
- 390px幅で横はみ出しなし、ページのJavaScriptエラーなし。
