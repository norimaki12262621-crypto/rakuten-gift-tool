# DECORTÉ TikTok用5枚画像

手動画像選択画面で00・01・03の各画像と色番号を確認してから、5枚プレビューへ進む。

- 1枚目：DECORTÉ／ルース パウダー／キャッチコピー／03の選択画像。
- 2〜4枚目：00 translucent、01 crystal translucent、03 luminous pinkを各選択画像で紹介。
- 5枚目：3色の画像・色番号・色名を並べて比較。
- 各Canvasの実寸は1080×1920px。番号ボタンで1枚ずつ表示し、PNGとして個別保存する。
- 淡いピンク、レース、パール状の線、きらめきはCanvasの図形で描く。商品写真は選択元の全体を縦横比を維持して配置し、加工・切り抜き・AI再描画はしない。
- 写真URLは選択したAPI画像の同じパスを使用し、サイズパラメータのみ1000px以内の指定に変更する。元画像の実解像度を超える情報は生成しない。
- 価格・効能・肌質への適合などは投稿画像内で断定しない。色名はDECORTÉの00・01・03に対応。その他商品はこの専用テンプレートの対象外として画像選択へ戻す。
- PR表記と、画面・光による色の見え方についての注記を各画像に入れる。

## ローカル起動

Node.js 24以降で、リポジトリのルートから実行する。外部パッケージのインストールは不要。

```sh
NODE_USE_ENV_PROXY=1 node scripts/dev.cjs
```

必要ならPORTでポートを変更する。APIと画像のHTTPリクエストは環境のプロキシとCA信頼を維持する。
Vercel形式のAPIルートに加え、同一オリジン画像取得用の`api/rakuten-image.js`を追加。
画像APIはHTTPSの`thumbnail.image.rakuten.co.jp/@0_mall/`だけを許可し、リダイレクト不可、JPEG/PNG/WebPのみ、15秒・3MB以内に制限する。
画像取得に失敗した場合は不完全なPNGを生成せずエラーを表示する。選択画面に戻って再試行できる。

## 実施した確認

- 手動確認済み3色の実画像をHTTP 200で取得。
- 5枚それぞれのPNG保存と1080×1920pxを確認。
- 色順・個別切り替え・スマホ390px幅・文字と画像の欠けを確認。
- 選択画像変更時の確認解除、3色未確認時のプレビュー禁止を維持。
- 画像取得失敗時の書出し禁止と選択内容の保持。
- 既存ランキングは実APIで60件取得・5件表示。選択操作によるランキング書換えなし。
- `node tests/rakuten-image.test.cjs`で7件通過（許可先・画像バイト保持・上流403・形式・容量・接続失敗の確認）。

成果物は実行環境の`/workspace/rakuten-gift-tool-local/final-deck/`にPNG5枚、ブラウザスクリーンショット、単独プレビューHTML、ZIP、画像出典manifestを保存。
