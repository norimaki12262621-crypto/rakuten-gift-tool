# TikTok用・商品画像の手動選択

メイン画面の「TikTok用5枚画像をプレビュー」から、00・01・03の画像選択画面を開く。

1. 色番号の「画像を選ぶ」を押す。
2. 楽天APIの商品名検索、またはランキング・フリーキーワード検索結果の取り込みで画像候補を集める。
3. 画像サムネイルをクリックする。商品名、商品名から読み取れる色番号、画像URL、楽天の商品ページURLが表示される。
4. 画像と商品ページを照合し、本体と色番号が正しいことを確認してチェックを入れる。商品名に00などが含まれていても自動では確定しない。複数色・未判定・選択色と異なる商品名には注意表示を出す。
5. 3色すべての確認後、「3色を確定して5枚プレビューへ」を押す。

## 動作

- 画像を変更した色の確認は解除される。他の色には影響しない。
- 画像読込失敗、未選択、商品ページURL未取得では確定できない。
- 検索失敗・該当なしでも既存候補と選択内容を保持する。
- 検索候補は累積し、同じ商品・同じ画像の重複は除く。
- 5枚プレビューは手動選択した画像を使う。選択元の商品名・商品ページと画像の対応を保持し、ランキング配列を変更しない。
- DECORTÉ専用の5枚デザインでは価格を表示せず、選択元の商品ページへ誘導する。
- 選択内容はページを開いている間だけ保持する。再読込すると選び直しとなる。
- APIの画像をそのまま表示し、削除・AI再描画・商品ページのスクレイピングを行わない。
- 既存のキュレーションJSONを自動確定の根拠にはしない。

## ブラウザでの検証

実APIの商品検索と、API取得済みの実商品レコードを用いた再現可能なUI検証を実施。

- 3色の独立選択、確認前のプレビュー禁止、3色確認後の5枚表示。
- 選択した画像URLが各商品スライドへ渡ること。
- 選択画像の変更で確認解除、再オープンで状態保持。
- API失敗・空結果でも選択を保持。
- 読込失敗画像の選択禁止、商品ページURLのない候補の確定禁止。
- 01と101の区別、商品名のHTML文字列を実行せず表示、候補の重複排除。
- 390px幅で横はみ出しなし。
- 画像選択操作でランキングデータが変わらない。
- 既存ランキングは実APIで60件取得・5商品表示、JavaScriptエラーなし。

Webサイトへのデプロイは行っていない。
