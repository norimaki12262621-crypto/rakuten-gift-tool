# TikTok用商品画像の選定ルール

楽天APIの先頭画像を無条件に採用せず、複数の商品・画像候補を比較して目視確認する。

## 優先順位

1. 商品本体が大きく写っている。
2. 販促バナー・ショップロゴがない。
3. 色番号が商品ページの情報と一致している。
4. 高画質で明るい。
5. 3色の見た目に統一感がある。

## 選定時の確認

- API商品名・商品コード・画像・価格・リンクを同じ商品レコードにひも付ける。別商品の価格や画像と混ぜない。
- 01と101を取り違えず、複数色・容量の共通ページを単色確定として扱わない。
- 箱だけ、配送説明、口コミ、特典や他商品、色一覧だけの画像は除外する。
- 箱と本体が並ぶ場合は本体が主役のものを優先する。
- 画像内の色番号・色名と、楽天APIが返す商品名を照合する。ページ本文を直接検証していない場合はその範囲を区別する。
- 商品容器やパフに元からあるDECORTÉブランド表示はショップロゴと区別する。
- ショップの文字を消さず、AIで描き直さず、別商品画像に置き換えない。
- 条件を満たす候補がなければ現在の採用画像を残し、不足条件を報告する。
- 同一画像のサイズ指定を変更して取得する場合も、実際の画素数・画質を確認する。

## 今回の採用案

`docs/tiktok-decorte-image-selection.json` の `selected` に新版、`previousSelected` に旧版を保持。
00・01・03とも wj-yakugyo の単色商品レコードに対応する実画像を選定。
本体・蓋・パフが大きく、箱・販促バナー・ショップロゴがない。
画像内の00 translucent / 01 crystal translucent / 03 luminous pinkとAPI商品名を照合。
同じ白背景・撮影構図で、容器と粉の色が見える。600px角以内の原画像を取得し目視確認。
楽天の商品ページ本文の直接取得は実施せず、色一致の検証根拠はAPI商品名・商品コード・画像内表記。

今回は3色の画像選定と横並び比較まで。既存ランキングや5枚プレビューの参照画像は変更しない。
5枚のデザイン制作やデプロイには進まない。
